Android 32 bit Deprecation

Earlier this year, we gave you a heads up that the full migration to Jagex Accounts would be taking place later this year on 17 November 2026

On this date, all Legacy accounts will need to make the one-time jump to Jagex Accounts. All you’ll need is your Username or Login Email and Password. If you haven’t upgraded by this date, you’ll be unable to log in until you’ve upgraded.

Previously, we mentioned Steam, Apple, Google & Game Center logins wouldn’t need to do anything. While that remains true for logging in, you will need to create a Jagex Account if you decide to use the Launcher or access some website features (like Support), which ensures we can offer a unified experience for all accounts.

If you haven’t upgraded yet, you’ll see some new reminders when you go to log in to RuneScape or Old School RuneScape. We recommend getting everything sorted whenever it best suits you now just to avoid any unwanted disruption after this date.

Android 32 bit Deprecation

From June 24th, Old School RuneScape will no longer be available on devices running 32 bit versions of the Android operating system, as client version 239 and onwards do not support 32 bit Android.

Therefore, existing installs on these devices will no longer be able to update or access the game.

Find out more information on this change, here.

Game Updates

Our weekly game updates will usually take place on Wednesdays. Here's what you can expect with each week's game update:

  • 10:45 UTC: 45-minute shutdown timer appears in-game
  • 11:30 UTC: Game goes offline
  • ~11:30 UTC: The game comes back online
Weekly Maintenance

We also have weekly maintenance updates that usually take place on Tuesdays at 9:00 UTC. Every few weeks the maintenance window will start at 11:00 UTC instead. Here is what you can expect with your usual maintenance window:

  • 9:15 UTC: 45-minute shutdown timer appears in-game.
  • 10:00 UTC: Game goes offline.
  • ~10:30 UTC: The game comes back online.
